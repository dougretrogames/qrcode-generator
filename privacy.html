Política de Privacidade

Última atualização: Agosto de 2026

🔒 Privacidade Total: Respeitamos integralmente a sua privacidade. Esta ferramenta foi desenvolvida sob o conceito de Privacy by Design — nenhuma informação digitada ou gerada sai do seu navegador.

1. Coleta e Armazenamento de Dados

Nós não coletamos, não transmitimos e não armazenamos nenhuma informação pessoal ou conteúdo gerado.

Qualquer texto, URL, senha de Wi-Fi, telefone ou dado inserido no campo de texto é processado em tempo real e desenhado diretamente no elemento HTML5 <canvas> pelo seu próprio dispositivo.

2. Processamento Local (Client-Side)

Diferente de geradores tradicionais que enviam seus dados para um servidor para renderizar imagens, este projeto utiliza a biblioteca JavaScript qrcode-generator executada localmente no seu computador ou celular. Isso garante que:

  • Nenhum log com seus dados é gravado;
  • Nenhum banco de dados armazena os seus códigos gerados;
  • A ferramenta funciona com máxima privacidade mesmo para dados sensíveis.

3. Cookies e Rastreamento

A nossa aplicação:

  • Não utiliza cookies de rastreamento, publicidade ou identificação;
  • Não utiliza ferramentas de terceiros para análise de perfil comportamental;
  • Não exibe anúncios publicitários de redes de terceiros.

4. Carregamento de Recursos Externos (CDNs)

Para o funcionamento adequado da interface e ícones, a página carrega os seguintes recursos estáticos:

  • jsDelivr: CDN utilizada para servir o script de cálculo matemático dos módulos do QR Code.
  • Simple Icons CDN: Utilizada para carregar vetores (SVGs) oficiais das marcas e redes sociais quando ativada a opção correspondente.

Essas redes de distribuição de conteúdo podem registrar solicitações HTTP padrão (como endereço IP e cabeçalhos de requisição) estritamente necessárias para a entrega técnica dos arquivos estáticos.

5. Permissões do Navegador

A funcionalidade "Compartilhar" utiliza a API nativa do navegador (Web Share API), acionando o menu oficial do seu sistema operacional para envio da imagem gerada para outros aplicativos. Nenhuma permissão especial ou invasiva é solicitada.

6. Conformidade com a LGPD e GDPR

Por não realizar coleta, tratamento ou armazenamento de dados pessoais em servidores, o serviço cumpre integralmente os princípios da Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018) e do Regulamento Geral sobre a Proteção de Dados da União Europeia (GDPR).
